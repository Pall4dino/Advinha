# Projeto de Engenharia de Software

🎯 Jogo de Adivinhação em Python

Um clássico jogo de adivinhação de números desenvolvido em Python, onde o objetivo é descobrir um número secreto entre 1 e 100 com um limite de tentativas!

🕹️ Como o Jogo Funciona

O computador escolhe aleatoriamente um número inteiro entre 1 e 100.
O jogador tem 7 oportunidades (tentativas) para acertar qual é o número.
A cada palpite incorreto, o jogo dá uma dica informando se o número secreto é maior ou menor que o valor informado.
O jogo termina se o jogador acertar o número (vitória) ou se esgotarem as 7 tentativas (derrota).
